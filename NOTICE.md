## `include/macro.inc`

The assembler macros every generated `asm/*.s` file includes (how function symbols
are declared and ended, plus names for the CPU's COP0 and floating-point
registers). It is the standard macro file that splat-based N64 projects use, and
this copy's exact origin is not recorded. [splat](https://github.com/ethteck/splat)
is MIT licensed, and so are the projects that share this file; if it came from any
of them, their terms are the same MIT terms as this repository's.
